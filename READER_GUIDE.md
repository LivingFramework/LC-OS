# Reader Guide

**Purpose:** Help readers enter the LC-OS research archive from the right starting point.

LC-OS is not a single paper, a software package, or a template library. It is a research corpus: eight papers, one AI-authored ledger, and supporting research architecture that together document a governed approach to long-horizon human–AI collaboration.

## What This Repository Is

This repository is the scholarly archive for LC-OS. It contains:

- Eight published papers
- The Mahdi Ledger
- Research architecture documents
- Citation metadata
- Term definitions
- Corpus maintenance protocols

It is designed to make the research transparent, navigable, and citable.

---

## What This Repository Is Not

This repository is not primarily:

- A software package
- A template library
- A quick-start implementation kit
- A product repository

Those operational materials belong in [LC-OS Project](https://github.com/LivingFramework/LC-OS-Project).

---

## The Core Argument in One Paragraph

LC-OS argues that long-horizon human–AI collaboration fails not mainly because models are insufficiently capable, but because collaboration lacks governance: stable artefacts, explicit protocols, drift detection, repair mechanisms, and validation. Across the corpus, reliability is treated as an emergent property of the human–AI system and its surrounding architecture, not as a property of the AI model alone.
